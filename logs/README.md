# Day logs

One file per unattended research day, written by the session running
`prompts/standing-loop.md`.

```
logs/
  YYYY-MM-DD.md          append-only, one entry per cycle
  YYYY-MM-DD-STATUS.md   written once, when the day stops
```

**Append-only.** A cycle's entry is never rewritten. If a later cycle
overturns an earlier conclusion, the later entry says so and names the
cycle it overturns. The sequence of what was believed when is the point; a
log tidied into a coherent narrative is a log that has lost its evidence.

A cycle entry records what was attempted, what was concluded, **what
blocked**, and what was filed. The blocks are the most useful column: a day
of blocked work is a day that tells the overseer what to unblock, and a log
that reports only what succeeded is a log nobody can act on.

These are logs, not results. Nothing here is cited by a write-up under
`explain/` or by a run under `runs/`. Results live in those places with
their evidence; this directory records how the day went.
